تحليل العملاء — النشاط والاتجاه والتركز

تُحفظ لقطة شهرية من كويري SAP (مبيعات آخر ١٢ شهر + الرصيد لكل عميل) على السيرفر المشترك، وتُصنَّف العملاء تلقائياً: نشط، متراجع، جديد، خامل، مع مؤشرات التركز وشهور الذمة واستغلال السقف، ومقارنة تلقائية مع اللقطة السابقة.
👤 — —
التصنيف: نشط = مبيعات بآخر ٣ أشهر · متراجع = آخر ٣ أشهر أقل من نصف الـ٣ قبلها · جديد = بدأ الشراء بآخر ٣ أشهر · خامل = لا مبيعات بآخر ٣ أشهر
تنبيهات: رصيد فوق السقف · شهور ذمة > ٣
1 إدخال لقطة جديدة — كويري تحليل العملاء
شغّل الكويري التالي في SAP والصق نتيجته تحت (مع سطر العناوين). الأعمدة M0..M11: M0 = الشهر الحالي (شهر تاريخ اللقطة) رجوعاً حتى M11. عدّل مصدر المبيعات حسب نظامك إذا لزم:
📄 عرض الكويري المقترح (SAP B1 HANA) SELECT C."CardCode" AS "رمز العميل", C."CardName" AS "اسم العميل", IFNULL(S."SlpName",'') AS "المندوب", C."Balance" AS "الرصيد", C."CreditLine" AS "السقف الائتماني", SUM(CASE WHEN D."MDiff"=0 THEN D."Amt" ELSE 0 END) AS "M0", SUM(CASE WHEN D."MDiff"=1 THEN D."Amt" ELSE 0 END) AS "M1", SUM(CASE WHEN D."MDiff"=2 THEN D."Amt" ELSE 0 END) AS "M2", SUM(CASE WHEN D."MDiff"=3 THEN D."Amt" ELSE 0 END) AS "M3", SUM(CASE WHEN D."MDiff"=4 THEN D."Amt" ELSE 0 END) AS "M4", SUM(CASE WHEN D."MDiff"=5 THEN D."Amt" ELSE 0 END) AS "M5", SUM(CASE WHEN D."MDiff"=6 THEN D."Amt" ELSE 0 END) AS "M6", SUM(CASE WHEN D."MDiff"=7 THEN D."Amt" ELSE 0 END) AS "M7", SUM(CASE WHEN D."MDiff"=8 THEN D."Amt" ELSE 0 END) AS "M8", SUM(CASE WHEN D."MDiff"=9 THEN D."Amt" ELSE 0 END) AS "M9", SUM(CASE WHEN D."MDiff"=10 THEN D."Amt" ELSE 0 END) AS "M10", SUM(CASE WHEN D."MDiff"=11 THEN D."Amt" ELSE 0 END) AS "M11" FROM OCRD C LEFT JOIN OSLP S ON S."SlpCode"=C."SlpCode" LEFT JOIN ( SELECT "CardCode", (YEAR(CURRENT_DATE)*12+MONTH(CURRENT_DATE))-(YEAR("DocDate")*12+MONTH("DocDate")) AS "MDiff", "DocTotal" AS "Amt" FROM OINV WHERE "CANCELED"='N' UNION ALL SELECT "CardCode", (YEAR(CURRENT_DATE)*12+MONTH(CURRENT_DATE))-(YEAR("DocDate")*12+MONTH("DocDate")), -"DocTotal" FROM ORIN WHERE "CANCELED"='N' ) D ON D."CardCode"=C."CardCode" AND D."MDiff" BETWEEN 0 AND 11 WHERE C."CardType"='C' GROUP BY C."CardCode", C."CardName", S."SlpName", C."Balance", C."CreditLine" ORDER BY C."CardCode";
📊
